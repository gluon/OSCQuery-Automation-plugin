# spikes

Throwaway programs that answer one question each before core code depends on the answer. A spike
never migrates into `src/`, and each ends with a written pass or fail in
[`docs/spikes/`](../docs/spikes/), after which the spike's code is deleted.

The first is devplan **Phase 1**: an 8-slot VST3 and AU measuring rename and hide behaviour in
the hosts on the bench.
